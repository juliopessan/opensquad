## 💾 Execution Notes

### Performance Implications (Econômico Mode)
- Lean pipeline: Research → Strategy → Copy → Review
- 1-2 tasks per agent (not 3-5)
- Single-pass creation, lightweight review
- No A/B variants (para speed)

### Channel Priorities (from research)
1. **LinkedIn:** Primary (procurement, marketing decision-makers)
2. **Email:** Secondary (nurture campaigns)
3. **Landing Pages:** Tertiary (conversion optimization)
4. **Instagram:** Tertiary (brand building, but emerging)

### Copy Principles to Remember
- Avoid corporatês → human language
- Focus on transformation → not features
- Incorporate psychology → reciprocity, urgency, social proof
- Structure: Problem → Solution → Proof → Action
